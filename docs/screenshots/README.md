# Screenshots

Drop your screenshots here so the main `README.md` can display them.
Expected file names (PNG, framed in a device mockup looks best):

| File | What it shows |
|------|---------------|
| `desktop.png` | Desktop 3-pane layout, in a laptop/computer frame |
| `mobile-pwa.png` | The PWA on a phone (iPhone frame) |
| `tablet.png` | The mobile/tablet layout on a tablet (iPad frame) |

Tips:
- Use transparent-background PNGs so the device frame blends with GitHub's light/dark themes.
- Keep them reasonably sized (a few hundred KB each) — they ship with the repo.
